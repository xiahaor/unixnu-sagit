# 发布说明（2026-11-16）

本仓库是 **小米 6（sagit / MSM8998）上从源码构建 XNU 并跑到自写用户态** 的完整工程记录，
现作为开源项目归档发布。用户态能力的扩展（定时器/多线程等）不再作为本项目目标，
相关排查与结论保留在文档中供后续参考。

## 一、成果概览

启动链：

```
XBL → ABL → EDK2/Mu-Silicium → UniXNU → DarwinBoot
    → XNU 8796.141.3（源码构建，非 Apple kernelcache 补丁）
    → RamBlock 发布 8 MiB HFS+ RAM 盘 → hfs: mounted sagitroot
    → /sbin/launchd（自写 freestanding arm64 PID1，无 libc）
```

已验证能力（全部真机 + 屏幕日志为证）：

| 类别 | 能力 |
|---|---|
| 进程 | posix_spawn 服务列表、退出码解析、wait4 回收、崩溃监督重启（3 次上限） |
| 信号 | kill SIGTERM/SIGKILL，status 解析（sig=15/9） |
| VFS | open/read/write/mkdir/rename/unlink/rmdir/getdirentries64、mount(MNT_UPDATE) 重挂可写 |
| IPC | 父子进程经 HFS+ 文件交换数据 |
| VM | mmap/munmap 匿名页 |
| 图形 | 内核 `kern.sagitfb` 写矩形到 framebuffer、`kern.sagitfbinfo` 读几何（1080x1920/32bpp/rowbytes=4320） |
| 控制台 | devfs + /dev/console |

完整过程见 [构建记录.md](构建记录.md)（每步有屏幕证据），技术总结见
[报告-小米6-XNU移植-20261115.md](报告-小米6-XNU移植-20261115.md)。

```
adb push out/v124/boot-sagit.img /sdcard/Download/
adb shell "dd if=/sdcard/Download/boot-sagit.img of=/dev/block/sde40"
```

⚠️ 刷写前务必备份 stock boot 分区：`dd if=/dev/block/sde40 of=/sdcard/Download/boot-stock.img`。

## 三、已知问题（记录在案，未作为本项目目标）

1. **定时器中断未工作**：内核按 `ARM64_BOARD_CONFIG_BCM2837` 构建，在 MSM8998 上缺少
   GICv3 的 timer/IPI 引导；阻塞睡眠（tsleep/poll）无法唤醒。参考实现见
   `ref-ios_sagit/tools/patches/zz-sdm835-platform.patch`（同作者的 ios_sagit 项目）。
2. **多线程**：`bsdthread_register/create` 与 `thread_resume` 均成功，但"线程未执行"的结论
   受上述假睡眠问题污染，未能定论（详见构建记录 2026-11-15 各节）。
3. **UFS 块设备写**：ABL 留下的控制器状态无法安全接管，已回滚。
4. **真 iOS 用户态**：需要解密系统盘与 trust cache，不在本项目范围。
