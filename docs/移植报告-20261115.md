# 小米 6（sagit）跑 XNU：移植报告（2026-11-15）

> 目标：在 Xiaomi Mi 6（MSM8998 / 骁龙 835，Android 机型）上，通过 UEFI 启动苹果的
> XNU 内核，并一路跑到自己的多进程用户态。
>
> 本文只写**已经真机验证**的事实，每一条都能在 [构建记录.md](构建记录.md) 里找到屏幕日志证据。

## 1. 最终成果

```
XBL → ABL → EDK2/Mu-Silicium → UniXNU 菜单 → DarwinBoot
    → XNU 8796.141.3（ios-16.7.16-20H392）
    → RamBlock 把 payload 里的 8 MiB 镜像发布为 IOMedia
    → 源码编入内核的 HFS+ 挂根（hfs: mounted sagitroot on device 0:0）
    → exec /sbin/launchd（自编 arm64 静态 PID1）
    → init 拉起服务、监督崩溃、处理信号、VFS 读写、mmap —— 全部真机跑通
```

| 0030 | UFS 启动钩子 | 让源码存储类在启动时注册 |
| 0031 | NativeUfs personality | 驱动可被 IOKit 匹配 |
| 0032 | 重复类改成日志 | 源码存储类与 kext 冲突不再 panic |
| 0033 | 控制台镜像到保留内存 | 为将来日志持久化铺路（本机静态映射只覆盖前 256 MB，暂未启用） |

另外把 Apple 公开的 **HFS+ 源码（hfs-627.100.6，与 kernelcache 版本一致）** 编译进内核：

workqueue/cprotect 兼容头等适配。

## 3. 踩过的硬坑（教训）

1. **HFS+ 编译**：`kext-config.h` 要靠 iOS 版 `TargetConditionals.h` 才能选对配置，
   否则 `CONFIG_PROTECT` 等全是 macOS 分支；C 文件还要 `-UXNU_KERNEL_PRIVATE` 才能拿到
   `ubc_create_upl`。
2. **根不是 HFS**：mos 挂载失败时 mockfs 会抢先成为根，诊断行 `rootfs=mockfs` 是关键证据；
   把 mockfs 的 `vfc_mountroot` 置 NULL 后 HFS 才真正挂上。
3. **AMFI 未加载**：`IOTaskHasEntitlement` 会解引用空 `amfi` 指针 → 内核数据 abort；
   加载前判空返回 false 即解决。
4. **PID1 栈只有 8 字节对齐**：AArch64 开栈对齐检查，第一条用 SP 的指令就
   `EXC_ARM_SP_ALIGN` → SIGBUS；用户态入口先对齐 SP。
5. **syscall 要检查 CARRY**：XNU 用 carry 表示错误、x0 返回 errno；忽略 carry 会把
   `-ECHILD` 误读成 pid。
6. **fork 不行、posix_spawn 行**：静态非 PIE 的 PID1，fork 返回子 pid 但子进程不运行、
   wait4 得 `-ECHILD`；`posix_spawn(244)` 一切正常。
7. **getdirentries64 才是 64 位布局**：旧的 `getdirentries(196)` 名字会错位。
8. **根默认只读**：`MNT_RDONLY|MNT_ROOTFS`，要 `mount(MNT_UPDATE)` 重挂；mount 的 `data`
   不能传 NULL（HFS update 会 copyin 挂载参数）。
9. **UFS 控制器接管不可行**：ABL 留下错误态（`IS=0x400`），停队列/清状态会把控制器挂死；
   已回滚，只保留只读诊断。

## 4. 复现步骤（简版）

1. 工具链与源码：见 [依赖清单.md](依赖清单.md)；内核用 `unixnu-sagit/tools/build-xnu-sagit.sh`；
2. 固件：`edk2-msm8998` 的 `Msm8998Pkg` + `unixnu-sagit/firmware/SagitPkg` 覆盖层；
3. 用户态：`unixnu-sagit/tools/build-launchd-stub.sh` 生成 `/sbin/{launchd,hello,…}`；
4. 根镜像：`mkfs.hfsplus` 建卷 → 用 `scripts/install-into-rootfs.sh`（需要 root 的宿主机）
   写入 `/sbin` 与 `/dev` 目录；
5. 打包：`mksagit-payload.py --initrd root.img` + `build-sagit-boot.py`（golden 固件基线
   `out/v6/boot-sagit.img`）；
6. 刷入：`scripts/auto-flash.sh out/vNN/boot-sagit.img`（需设备在 recovery）。
