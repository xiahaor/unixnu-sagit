# 小米 6（sagit）UniXNU 工程骨架

给 Xiaomi Mi 6（`sagit`，MSM8998 / 骁龙 835）跑 **UniXNU** 的本地工程目录。
UniXNU 是"在非 Apple ARM64 设备上通过 UEFI 跑 iOS/macOS 内核（XNU）"的引导环境
（[unixnu.com](https://unixnu.com/)），类似 OpenCore：

```
XBL → ABL → EDK2/Mu-Silicium（UEFI 固件）→ UniXNU.efi（引导管理器）
    → DarwinBoot（XNU loader）→ XNU 内核 → （目标：iOS 用户态）
```

本目录当前处于**「骨架 + 依赖核对」阶段**（2026-11-13 与用户确认的 A 方案）：
仓库已就位、官方 resolver 已跑通到 `tree`；**尚未**构建内核、固件和 boot 镜像，
因为还缺工具链与 iOS IPSW 这两类外部输入（见 [依赖清单.md](依赖清单.md)）。

> 路线已定：**A（UniXNU 框架）** —— 见 [路线A-移植计划.md](路线A-移植计划.md)。
>
> 设备列表调研（小米 6 无可用 UniXNU 条目、同 SoC 的 cheeseburger 与列表外的 ios_sagit 都比它成熟）见
> [设备列表与候选基座.md](设备列表与候选基座.md)。

## 当前状态（2026-11-15）

**已完成：真机上从 UEFI 一路启动到多进程用户态。**

```
XBL → ABL → EDK2/Mu-Silicium → UniXNU → DarwinBoot
    → XNU 8796（源码编入 HFS+ 与 RamBlock）
    → 8 MiB RAM 盘 HFS+ 根（hfs: mounted sagitroot）
    → /sbin/launchd（自编 freestanding PID1）

        ├── mmap/munmap 匿名页

```

## 当前阻塞（详见依赖清单）

1. **没有 root**：容器带 `no new privileges`，`sudo` 直接失败；而 XNU 工具链的官方安装脚本要 `apt-get install` 一批包（clang/lld/mtools/dtc/flex/bison/tcsh/unifdef/libbsd-dev…），并默认写 `/opt`。主机现在缺 `clang`、`dtc`、`mtools`、`flex`、`bison`、`tcsh`、`unifdef`、`lzfse`。
2. **没有 IPSW**：内核预链接要求 iPhone 8（`iPhone10,1` / `d20ap`）iOS **16.7.16 (20H392)** 的恢复镜像，从中取 kernelcache（sha256 固定 `ae36144edbd1aebce562b662ed0c19053c95026d0950eeab5c9e695fe72e2f71`）、DeviceTree、trust cache。
3. **没有 ARM GNU 工具链**：EDK2 固件构建要 `aarch64-none-linux-gnu-gcc` 13.2（`tools/build-sagit-edk2.sh:19`），可从 developer.arm.com 下 tarball，**不需要 root**。
4. **fastboot 未安装**（`adb` 有），且当前这台服务器上 `adb devices` 为空 —— 真机刷写前需要先确认手机怎么连到本机。

## 建议的下一步（按依赖顺序）

1. 定"谁来装工具链"：用户给 root / 我把 deb 包 rootless 解包到 `toolchains/` / 换一台有 sudo 的机器（三选一，见依赖清单）。
2. 下载 iPhone 8 iOS 16.7.16 (20H392) IPSW，解出 kernelcache + DTB + trustcache，落到 `ipsw/` 并校验 sha256。
3. 下载 ARM GNU 13.2 tarball 到 `toolchains/`，验证 `aarch64-none-linux-gnu-gcc --version`。
4. 修复设备仓库与官方记录的唯一硬错误：`porting.toml:6` 的 `os_profile = "ipados-17.7.11-21H461"` 与 `board.toml:13` 的 `ios-16.7.16-20H392` 不一致（上游 docs 生成器因此把该设备标记 `record_state = "invalid"`）；改一行即可。
5. 再按 README/`AGENTS.md` 的顺序跑：`build-xnu-sagit.sh` → `mksagit-payload.py` → `build-sagit-edk2.sh` → `fastboot flash boot`。

## 注意：git 镜像重写

用户 `~/.gitconfig` 里有：

```ini
[url "https://gitclone.com/github.com/"]
	insteadOf = https://github.com/
```

该镜像目前返回 502，会连带让 `git submodule`、`unixnu fetch` 里的子模块克隆全部失败。
本次所有克隆都通过临时全局配置绕过：

```sh
printf '[http]\n\tpostBuffer = 524288000\n' > /tmp/gitcfg-nomirror
GIT_CONFIG_GLOBAL=/tmp/gitcfg-nomirror git clone ...   # 或 git submodule update ...
```

跑 `./unixnu fetch` / `build-*.sh` 时同样建议带上 `GIT_CONFIG_GLOBAL=/tmp/gitcfg-nomirror`。
（没有改动用户自己的 `~/.gitconfig`。）
